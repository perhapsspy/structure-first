# 여러 책임 경계의 리뷰

여러 책임 단위와 그 조합 계약에 걸친 버그 리뷰에 이 절차를 쓴다. 집중된 로컬 리뷰는 일반 계약 추적과 검증을 따른다.

## 조사 초안

요청한 부작용과 읽기 전용을 포함한 공개 결과에서 근거를 제공·해석하는 owner를 역추적한다. 작은 임시 노트에 구별되는 생산자–소비자–약속된 결과 경계를 식별한다. 동등한 의무만 합치며 같은 기능 이름이라는 이유로 다른 결과를 합치지 않는다.

중요한 경계에서 원천 사실·이력으로 계약의 허용 조건 또는 필수 결과를 밝히고, 구현의 guard 및 데이터·근거 변환과 따로 비교한다. 코드가 금지된 결과를 만들거나 필수 결과를 누락·왜곡하는 도달 가능한 반례를 시도한다. 상위 불변식과 다른 경로도 확인한다. 구체적인 대입과 결과 또는 미해결 전제를 남긴다. 정상 성공만으로 그 경계의 계약이 입증되지는 않는다. 집중 witness에는 기존 Verification 규칙을 적용한다.

초안 단계 경계에서 실제 초안·노트·테스트·결과를 반환한다. 이는 리뷰 owner에게 넘기는 중간 결과이며, owner는 사용자에게 완료를 알리기 전에 근거 비판과 통합까지 이어간다.

## 근거 비판

별도 리뷰 호출로 수행한다. 위임한 리뷰라면 같은 담당자를 원래 요청·전체 계약·소스·실제 초안 산출물과 함께 이어서 호출한다. 이전 노트·보고·시험은 주장과 증거이며, 범위의 정의나 신뢰할 계약 모델이 아니다.

이전 산출물에서 빠진 약속도 포함해 요청한 부작용·공개 결과의 중요한 약속에서 출발한다. 살피지 않은 약속이나 근거 없는 검토 범위 주장을 고른다. 소스 위치와 함께 계약이 요구하는 사실을 밝히고, 기존 코드·시험이 실제로 입증한 사실을 따로 밝힌다. 빠진 추론을 책임 있는 생산자와 소비자를 따라 추적한다. 도달 가능한 반례를 시도하고 필요하면 집중 probe를 쓴다. 구현 label이나 관련 사례의 성공은 빠진 사실을 입증하지 않는다.

확인된 발견을 관성적으로 재현하는 대신 유효한 witness를 재사용한다. 조사한 비판마다 약속·기존 증거·빠진 추론·결과만 남긴다. 증거로 반박되지 않은 발견은 유지하며 발견과 실행 재현을 구분해 결합 보고를 갱신한다. 기존 경계 증거 규칙을 적용하고, 비판을 이유로 전체 runtime이나 end-to-end 시험을 자동 요구하지 않는다.

## 총예산과 완료

현재 리뷰 예산 일부를 근거 비판에 남긴다. 조사·인계·대기·비판을 합산하며 비판에 새 전체 예산을 주지 않는다. 단계 경계에서 실제 남은 예산을 전달한다. 설정된 모델과 effort를 유지한다.

리뷰 owner는 원래 요청과 실제 증거에 맞춰 결합 발견을 통합한다. 소스 노출·일반 확언·발견 수는 검토 범위의 근거가 아니다. 확인한 경로·직접 넣은 사실·원래 코드가 만든 사실·남은 한계를 보고한다. 작업이 영구 기록을 요구하지 않으면 이 작업 노트는 임시로 둔다.
