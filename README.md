# Structure-First

[한국어](README.md) | [English](README.en.md)

## 요약

복잡한 기능을 고쳐도 중요한 흐름을 한눈에 읽을 수 있고, 작은 수정이 예상 밖의 부수 효과로 번지지 않게 합니다. 코드는 위에서 아래로 따라갈 수 있게 정리하고 테스트는 구현 세부 대신 지켜야 할 동작을 확인합니다.

## 빠른 시작

**설치**

```bash
npx skills add perhapsspy/structure-first
```

**바로 사용**

```text
$structure-first 를 활용해서 기능을 구현해줘
```

## 이런 때 사용

- 상태 분기/조건이 많아 코드가 위에서 아래로 읽히지 않을 때
- 작은 수정이 예상하지 않은 다른 동작까지 건드릴 때
- 리팩터링 후 테스트가 구현 세부에 끌려 자주 깨질 때

## 프롬프트 예시

```text
# 구현할 때
$structure-first 를 활용해서 기능을 구현해줘

# 기존 코드 개선 할 때
$structure-first 관점으로 코드를 분석하고 개선 제안 해줘

```
